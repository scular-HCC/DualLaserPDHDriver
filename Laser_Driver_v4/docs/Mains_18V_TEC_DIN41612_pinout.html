1  Power blades — P1–P8

10 A blades. Each supply is paired with an adjacent ground blade for a short return loop and current sharing (matters for the pulsed 5 A TEC). All nets below already exist on the board.

exists = net already in the schematic  ·  add = needs monitoring/control circuitry  ·  optional = nice-to-have.

¹ Remote sense is optional here. ±22V feeds downstream regulators that re-regulate, so backplane IR drop mostly doesn't matter. Sense is more useful on ±6V_TEC (linear headroom). Keep for margining/monitoring, otherwise reclaim those pins as spares.
² Earth. Safety/chassis ground conventionally bonds through the rack frame (front panel + card guides), not a connector pin. Pin Earth on c14 only if your backplane distributes earth — otherwise free c14 as spare.

Existing vs to-be-added

Only 7 nets exist today and are assignable now: +22V, -22V, +6V_TEC, -6V_TEC, GND, DGND, Earth. The PG_*, EN, HS_NTC readout, TEC_IMON, FAULT, and sense lines require circuitry to be added (the v3 rail-good / voltage-monitor blocks are a starting point).
