00Context & goal

Replace the kHz digital dither lock with a ~1–3 MHz analog derivative (slope) lock. This document is the design spec for the four new analog blocks plus the integration/cascade work. It accompanies four copy-paste KiCad blocks in Laser_Driver_v3/new_rf_blocks/.

The instrument is a differential thermometer: it reads the beat Δν = S·(T_B − T_A), S ≈ 2 GHz/K, over a ~60 s window. Because the measurement is ratiometric and material-defined, slow common-mode terms cancel and the figure of merit is within-60 s Allan deviation in equivalent kelvin. The kHz dither lock is thermal-/detection-limited at ~40 nK; an RF derivative lock pushes the within-window floor toward ~4–11 nK.

The number that decides everything Whether RF lands near ~4 nK (RAM slower than the 60 s window → cancels ratiometrically) or ~11 nK (in-band RAM survives) is set by the residual-amplitude-modulation (RAM) spectrum of the current-modulated laser. Every topology choice below is biased to add as little RAM as possible. The RAM spectrum must be measured early (§11) — it, not the electronics, is the likely floor.

This is not true PDH: the Q≈1e5 / 1.93 GHz cavity would need ~GHz modulation for dispersive PDH, unreachable by laser-current modulation or the AD9833. We modulate the laser frequency at Ω just above the DFB thermal/carrier FM crossover and demodulate the slope of the ring transmission — a high-frequency lock-in / derivative discriminator.

01Architecture & what changes

Per channel, the lock loop becomes: modulate laser current at Ω → ring imposes FM→AM on the transmitted light → wideband TIA → synchronous demod against a phase-set reference at Ω → low-pass → analog PI servo → correct the laser current setpoint. The Teensy keeps supervision and now monitors the baseband error rather than closing the loop.

03RF injection — bias-tee on the laser line

Add Replace in DFBLaser.kicad_sch. Block file: RF_Injection_BiasTee.kicad_sch.

Recommendation — bias-tee, not gate AC-couple Inject the RF current onto the laser line through a DC-block cap, with a series choke isolating the DC loop — not onto the IRLML6344 gate. Rationale: gate coupling drives the modulation through the FET's nonlinear transconductance, stamping that nonlinearity straight onto the optical amplitude — i.e. it manufactures RAM, the one term we cannot afford. The bias-tee keeps both the OPA192 DC loop and the FET out of the RF amplitude path, so the only RAM is the laser's intrinsic FM→AM. Fallback: if a 10 µH choke with adequate SRF/EMI proves impractical at the board level, revert to a small series-R + cap onto the gate above loop bandwidth — documented but not preferred.

Topology & sizing (per channel)

  • Series choke L_bt ≈ 10 µH (shielded RF inductor, SRF ≫ Ω) in the laser DC feed. Presents high impedance at Ω so RF current flows into the laser, not back into the FET/supply; passes DC freely.
  • DC-block C_bt ≈ 10 nF C0G couples the modulation source onto the laser node.
  • Drive resistor R_inj ≈ 2 kΩ (trim 1k–5k) sets modulation depth. Laser node is low-Z, so injected current ≈ V_src,pk / R_inj.
  • AC-couple C_ac ≈ 100 nF blocks the AD9833 DC offset before R_inj.
X_L(Ω) = 2π·Ω·L_bt = 2π·2 MHz·10 µH ≈ 126 Ω ≫ (R5 + r_laser ≈ few Ω) ✓ X_C(Ω) = 1/(2π·Ω·C_bt) = 1/(2π·2 MHz·10 nF) ≈ 8 Ω ≪ R_inj ✓ I_pk ≈ V_src,pk / R_inj = 0.6 V / 2 kΩ ≈ 0.30 mA pk (≈ prior dither 0.32 mA)

FM depth target. The prior dither (0.32 mA → ~96 MHz ≈ 0.1× HWHM) sets the scale. Keep the starting depth modest (~0.1–0.3× HWHM); R_inj is a trim so depth can be optimized for discriminator slope-vs-RAM once measured.

Flag — FM efficiency falls with frequency At MHz the laser FM is carrier-dominated (tens of MHz/mA) and lower than the DC thermal efficiency, so the real excursion for 0.30 mA will be smaller than the DC-scaled ~90 MHz. Final depth and Ω depend on the measured FM-response/crossover (§11, open item 1). Treat 0.30 mA as a starting point, not a target.

04Wideband transimpedance amplifier

Replace OPA380 ext-PD TIA in Readback.kicad_sch. Block file: Wideband_TIA.kicad_sch.

Recommendation — OPA858 (default), OPA818 if C_pd is large OPA858 (5.5 GHz GBWP, single +3.3–5.25 V) gives BW headroom far beyond the 15–30 MHz needed (≥5–10×Ω). Use OPA818 if the ring-transmission PD turns out high-capacitance. Note OPA858 is decompensated (min stable gain 7); if the noise-gain constraint below is awkward, OPA859 (unity-gain stable) is the drop-in alternative.

05Synchronous demod — mixer + phase reference + LPF

Add. Block file: Mixer_PhaseRef_LPF.kicad_sch.

Recommendation — AD831 mixer (AD633 fallback if Ω ≤ ~1 MHz) AD831 (double-balanced, to 500 MHz, low distortion) has full BW headroom across the entire 1–3 MHz target including the 3 MHz AD9833 ceiling, so demod gain/phase don't droop as Ω is tuned → minimal demod-introduced artifacts. AD633 (4-quadrant multiplier, DC-coupled, simpler, lower power) is the better choice only if the measured crossover lets Ω sit ≤ ~1 MHz — at 2–3 MHz the AD633's ~1 MHz full-power BW degrades both demod gain and phase stability. Decide after open items 1–2.

Phase reference — dedicated reference DDS per channel (Option B, chosen)

Decision — reference AD9833 per channel, not an analog all-pass Each laser gets its own drive DDS + reference DDS (4× AD9833 total). The reference DDS emits the same Ω as the drive and supplies the mixer LO; demod phase is set digitally via the reference DDS phase register, calibrated once in firmware against the live error signal — drift-free, no analog trim. This was preferred over the analog all-pass for stability and clean channel independence. Block: RefDDS_AD9833.kicad_sch (uses your real Interface:AD9833xRM part).

Why a dedicated DDS, not a multichannel chip. The AD9833/34/37/38 family is single-output — there is no "multichannel AD9833," and a single chip cannot emit the drive tone and a separately phase-shifted copy at once. The only true multi-channel DDS parts (AD9958 2-ch / AD9959 4-ch) are 500 MSPS / 1.8 V devices — large overkill for 1–3 MHz and a major departure from the existing 25 MHz SPI infrastructure. Four discrete AD9833 reuse all of it.

PHASE COHERENCE: all 4 AD9833 share the one 25 MHz Y_DDS (MCLK). Within a laser, drive & reference run identical frequency words → after a synchronized RESET their phase accumulators stay locked; relative phase = Δ(phase registers), constant (digital, no drift). INDEPENDENCE: each pair sets its own Ω → Ω_A ≠ Ω_B; cross-channel tones differ in frequency.

Integration into Laser_Control (Option B wiring)

  • Add 2× AD9833 (refs): laser A → DDS3 → LO1_REF; laser B → DDS4 → LO2_REF.
  • Shared SPI bus DDS_SCLK/DDS_SDATA (SPI Mode 2, 3.3 V, no level shift); each ref DDS gets its own chip-select DDS3_FSYNC/DDS4_FSYNC from a spare Teensy GPIO.
  • Shared clock MCLK_REF from the existing 25 MHz Y_DDS (same source that feeds the drive DDS) — mandatory for phase coherence.
  • Firmware: on lock acquisition, sweep the reference phase register to maximize the in-phase error (null quadrature); store per-channel. Re-cal only if Ω changes.

Post-mix low-pass (reject 2Ω, set baseband)

2-pole Sallen-Key, fc ≈ 50 kHz — above the loop bandwidth (tens of kHz), far below Ω and the 2Ω product (4–5 MHz). Start: R = 3.3 kΩ, C = 1 nF C0G (fc ≈ 1/(2πRC) ≈ 48 kHz).

06Analog PI loop filter

Add. Block file: PI_LoopFilter.kicad_sch.

Op-amp PI: input resistor R_i, feedback C_i in series with proportional R_p. Output sums into the existing DITH1_SUM/DITH2_SUM node at the OPA192 IN+ (reuse that net as the correction-summing point), so the slow servo trims the DC current setpoint with tens-of-kHz loop bandwidth.

Integrator unity-gain: f_i = 1/(2π·R_i·C_i) Proportional zero: f_z = 1/(2π·R_p·C_i) Start: R_i = 10 kΩ, C_i = 1 nF → f_i ≈ 15.9 kHz ; R_p = 1 kΩ → f_z ≈ 159 kHz
Flag — PI gains await measured discriminator slope; bound the authority Loop gain scales with the discriminator slope (V per Hz of detuning = TIA gain × ring slope × FM depth × demod gain), which isn't known until the slope is measured. The RC values above are a starting point. Also clamp the correction range (e.g. resistive divider / back-to-back clamp at the summing node) so the servo cannot push the laser past 100 mA / Vf — this couples into the DAC-to-current budget (§10).

Integrator hold / reset switch — Teensy LOCKn_EN

An SPST analog switch (e.g. ADG419, U831) sits across C_i. The Teensy drives it via LOCK1_EN/LOCK2_EN: HOLD/RESET the integrator while the supervisor sweeps to acquire, then RUN (switch open) once a zero-crossing is captured, handing the loop to the analog PI. This prevents integrator wind-up during acquisition and gives clean, repeatable lock capture. Map the switch's logic polarity (active-high/low) to the firmware's HIGH=RUN / LOW=HOLD convention.

Controller — Teensy 4.1 stays; it's now a supervisor The lock-in demod and the PI servo are analog, so the Teensy no longer does MHz real-time DSP. Its firmware (updated): programs the 4 DDS (dual-Ω, phase-coherent), sweeps the DAC to acquire, toggles LOCKn_EN, calibrates the demod phase via the reference-DDS phase register, and monitors the baseband error on LOCKn_IN. Needs 4 new pins (2× FSYNC, 2× LOCKn_EN) — see the port table in the firmware notes.

08Demote: 30 kHz AAF + Teensy lock-in → monitor

Demote. The RF lock is closed entirely in the analog domain (§3–6). Keep the OPA2141 2-pole 30 kHz AAF + Teensy ADC, but repurpose them to digitize the post-mix baseband error for logging, lock-status supervision and diagnostics. The lock path bypasses the AAF (the AAF would otherwise kill the MHz signal). No firmware lock-in math in the control loop; the Teensy reads the already-demodulated DC error.

11Open measurements (ordered)

  1. DFB1550LP FM response — efficiency & phase vs frequency; locate the thermal/carrier crossover (~0.1–2 MHz).
  2. Set Ω just above crossover (target 1–3 MHz, no higher). Picks AD831-vs-AD633.
  3. RAM spectrum — in-band flicker vs slow drift; decides ~4 vs ~11 nK.
  4. Ring-transmission PD capacitance — sizes the wideband TIA Rf/Cf/BW.
  5. Discriminator slope (V/Hz) — sets the PI loop gains.
